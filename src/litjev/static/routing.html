A question is escalated when v > λ, where v = log P(slow right) / P(fast right) is the value of thinking. It is a log ratio, not a difference, so it has no upper bound: a question the block rates three times more likely to be answered by the slow mode carries v ≈ 1.1 and is escalated at any price below that. At λ = -1 every question is escalated, which is always-think and needs no block; raising λ buys fewer escalations rather than none.

HOW IT WORKS / where these numbers come from

      
Routing does not ask the model a second time. It reads the hidden state the model has already computed.

      
The fast-thinking mode is still System 1: one forward pass, candidate logits read at the Answer: position, no token generated. The self-routing block holds the only trained weights, and it reads a state that same pass has already produced — so routing adds no forward pass of its own.

      
    
        
  1. The fast-thinking mode answers as usualIt encodes the state and the question and reads a candidate distribution p at the readout position, producing on the same pass the hidden state h. This step is identical to the System 1 page.
    2. 
        
  2. The block reads h and eight statistics of pIt returns the two modes' four joint outcomes o ∈ Δ⁴: both right, the fast one only, the slow one only, neither. The block is a 72 → 64 → 4 MLP — a few hundred kilobytes of parameters.
    3. 
        
  3. Confidence and the value of thinking followc = o₁ + o₂ is the probability the fast answer is right; v = o₃ − o₂ is the utility the slow-thinking mode is expected to add over the fast one — the value of thinking.
    4. 
        
  4. Compare it with the priceEscalate when v > λ. The price arrives on the request and never enters training, so one trained head covers the whole cost–accuracy curve: moving the slider does not change the model.
    5. 
        
  5. Escalated questions run the slow-thinking modeThe backbone's own thinking mode generates a trace, then the answer is read at the same Answer: boundary. The typed answer is still assembled from logits; nothing is parsed from the generated text.
    6. 
      

      

        
Which value is actually taken?
# one forward pass, which yields the hidden state too
p, h = fast(state, question)
# the self-routing block: hidden state + eight statistics of p
o = block(h, stats(p))            # in the 4-simplex
c = o[0] + o[1]                   # P(fast is right)
v = o[2] - o[1]                   # the value of thinking
escalate = v > lambda_            # the price comes from the request
answer = slow(state, question) if escalate else argmax(p)
v is a difference of two probabilities and so lies in [−1, 1]. When c comes from the decision head, diagnostics reports confidence_method as decision_head_outcome_v1; without a head it falls back to the distribution's concentration, normalized_gini_concentration_v1. The two are not interchangeable.

FieldSource and meaning

          
diagnostics.fields.*.escalation_gainFrom the self-routing block. This is v, computed as o₃ − o₂; without a decision head the field is absent.

          
diagnostics.fields.*.outcomeThe block's four joint-outcome probabilities, keyed as in OUTCOME_CLASSES.

          
diagnostics.fields.*.systemone if the fast-thinking mode answered, two if the question was escalated.

          
diagnostics.routing.escalatedThe question ids escalated on this request. lambda and budget are the values that actually applied.

          
diagnostics.timing.*Per stage, measured by the engine; the round trip and transport are measured by this page. Together they say where an escalation's time went.

          
result.usage.output_tokensTokens the slow-thinking mode actually generated. Zero when nothing escalates.
